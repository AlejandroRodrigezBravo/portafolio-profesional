La Porra Global.

MUNDIAL 2026 · FULL STACK

Ligas privadas de predicciones de fútbol, gestión de partidos y clasificación por puntos. Un monolito modular Java con interfaz React.

Java 21Spring Boot 3ReactMySQLJWT

Qué aporta

Conecta reglas de negocio, autenticación y experiencia de usuario en una aplicación full stack.

Dentro del proyecto

  • Módulos de usuarios, ligas, partidos, predicciones y rankings.
  • Puntuación de resultados: 3 puntos por marcador exacto y 1 por acertar el signo.
  • Código de pruebas con JUnit, Mockito y Testcontainers; configuración Docker Compose.

Tecnologías y estructura

Backend Java 21 y Spring Boot 3.3.5, persistencia MySQL, seguridad JWT e interfaz React con Vite. Organización por módulos de negocio.

Alcance actual

Proyecto lúdico sin apuestas con dinero real. El asistente de predicciones utiliza heurísticas sobre goles de partidos anteriores; no es un modelo de aprendizaje automático.
