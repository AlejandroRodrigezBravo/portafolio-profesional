MUNDIAL 2026 · DATOS & APIs

Portal de estadísticas con API FastAPI, clasificación, goleadores y rankings. Incluye un asistente de consultas sobre los datos disponibles.

PythonFastAPIJavaScriptJSON / CSV

Qué aporta

Muestra integración de fuentes externas, tratamiento de datos y una API que alimenta una interfaz web.

Dentro del proyecto

  • Endpoints para clasificación, partidos, equipos, goleadores y estadísticas de jugadores.
  • Servicios de sincronización y almacenamiento local en JSON/CSV.
  • Asistente que identifica consultas mediante reglas y construye respuestas a partir de las estadísticas.

Tecnologías y estructura

Backend Python/FastAPI, frontend HTML/CSS/JavaScript y servicios para consultar fuentes deportivas. El repositorio incluye automatizaciones de actualización en GitHub Actions.

Alcance actual

La disponibilidad y actualización de las estadísticas dependen de las fuentes externas y de su configuración. El asistente revisado funciona mediante reglas; no se presenta como un LLM entrenado.
