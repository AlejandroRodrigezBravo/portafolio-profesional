API de precios.

JAVA · PRUEBA TÉCNICA

Consulta de tarifas por producto, marca y rango de fechas, ordenadas por prioridad. Un ejercicio backend con pruebas de las distintas capas.

Spring BootSpring Data JPAH2JUnit / Mockito

Qué aporta

Ofrece a un entrevistador un ejemplo acotado para revisar consultas, respuestas HTTP y pruebas automatizadas.

Dentro del proyecto

  • Endpoint REST de consulta de precios y persistencia mediante Spring Data JPA.
  • Filtrado por marca, producto y fechas, con orden descendente de prioridad.
  • Pruebas del controlador para respuestas 200, 400 y 404, además de pruebas de servicio y repositorio.

Tecnologías y estructura

Spring Boot, Spring Data JPA, base de datos H2 y pruebas con JUnit, Mockito y RestAssured. El repositorio se llama GuidanceTest.

Alcance actual

Prueba técnica de alcance acotado. Las pruebas están en el repositorio; no se ha ejecutado la suite en esta revisión ni se publica un porcentaje de cobertura no medido.
