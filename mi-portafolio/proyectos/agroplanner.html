AgroPlanner.

PROYECTO PROPIO · EN DESARROLLO

Llevar el desarrollo backend y la inteligencia artificial a una necesidad concreta: la gestión agrícola.

Java / Spring BootReactPython / PyTorchONNX

El propósito

AgroPlanner es un proyecto SaaS agrícola orientado a cooperativas. Su alcance reúne cuaderno digital, tratamientos, alertas y diagnóstico con visión artificial.

Mi interés es conectar la gestión de la actividad agrícola con herramientas que ayuden a interpretar imágenes de cultivos y a organizar la información en una misma aplicación.

Mi contribución

Como creador y desarrollador full stack, trabajo en el backend Java/Spring Boot, la interfaz React y la integración de modelos de visión artificial.

El proyecto incorpora trabajo con 16 modelos de visión, PyTorch y ONNX. Esta integración permite conectar el desarrollo de modelos en Python con una aplicación del ecosistema Java.

Lo que conecta este proyecto

  • Desarrollo de un producto con backend e interfaz web.
  • Gestión de información y flujos del ámbito agrícola.
  • Integración entre tecnologías de aprendizaje automático y Java.

Estado y alcance

Es un proyecto en desarrollo. Esta presentación describe su enfoque y mi trabajo; no ofrece una demo pública ni resultados de precisión validados. El diagnóstico con imágenes se plantea como apoyo y requiere contrastar el contexto del cultivo.

DE LOS MODELOS A LA APLICACIÓN

Tres áreas de trabajo.

  1. Visión artificial
    Python y PyTorch para trabajar con modelos de imágenes.
  2. Integración
    ONNX como formato de intercambio de modelos y Java/Spring Boot para el backend.
  3. Interfaz
    React para la aplicación web.
