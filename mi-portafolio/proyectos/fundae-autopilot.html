FUNDAE Autopilot.

BACKEND SaaS · PROTOTIPO

Backend para gestionar empresas, expedientes formativos y participantes, con generación de documentos PDF y autenticación JWT.

Java 21Spring Boot 3FlywayOpenPDF

Qué aporta

Aporta un caso B2B: modelado de procesos, persistencia y generación documental en Java.

Dentro del proyecto

  • Módulos para empresas, clientes, expedientes, participantes y usuarios.
  • Generación de comunicaciones, listados y diplomas con OpenPDF.
  • Migraciones de base de datos con Flyway y documentación OpenAPI.

Tecnologías y estructura

Java 21, Spring Boot 3.3, MySQL, Spring Security/JWT, Flyway y OpenPDF. Incluye configuración de Docker y GitHub Actions.

Alcance actual

Prototipo en desarrollo. La comunicación con FUNDAE está simulada en el código; no ofrece una integración oficial operativa ni acredita validez oficial de los documentos.
